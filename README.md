# Shopping List

Home assignment: a two-screen shopping list application.

> Work in progress. Install and run instructions will be added as components are built.

## Components

| Folder | Description |
|---|---|
| `client/` | React + Redux Toolkit UI (screen 1: shopping list, screen 2: order summary) |
| `server-catalog/` | .NET 10 + Entity Framework + SQL Server: categories and products |
| `server-orders/` | Node.js + Elasticsearch: order storage |
